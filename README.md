# Personal Portfolio Website

This is a simple single-page portfolio website built with plain HTML and CSS. It is ready for GitHub Pages and uses placeholder content that you can replace with details from your resume.

## Files

- `index.html`: page structure and portfolio content
- `styles.css`: styling and responsive layout
- `assets/`: place your resume PDF and any future images here

## Customize The Site

Update the placeholder content in `index.html`:

- Replace `Your Name` with your actual name
- Update the About, Education, Experience, Skills, and Contact sections
- Replace the placeholder email, GitHub, and LinkedIn links
- Add your resume PDF at `assets/resume.pdf`

## GitHub Pages Deployment

1. Create a GitHub repository and upload these files.
2. Make sure `index.html` is in the root of the repository.
3. On GitHub, open the repository `Settings`.
4. Go to `Pages`.
5. Under `Build and deployment`, choose `Deploy from a branch`.
6. Select your default branch and the `/ (root)` folder.
7. Save the settings and wait for GitHub Pages to publish the site.

Your site URL will look similar to:

`https://your-github-username.github.io/repository-name/`

## Notes

- No build tools or framework are required.
- You can preview the site locally by opening `index.html` in a browser.
- If you later want a custom domain, GitHub Pages supports that as well.
